# Expression: how the site speaks

更新: 2026-11-04。対象: Home、機能（`/features`）、連携（`/integrations`）。
文言の正本は `shumoku-site-copy.ja.md`（サイト計画のコピー案）。由来と思想の正本は製品リポジトリの
`docs/ORIGIN.md` と `docs/PHILOSOPHY.md`。ここではそれらを複製せず、画面表現への写像だけを記録する。

## 由来から導いた三つの態度

| 由来・思想 | 画面での態度 |
| --- | --- |
| 撞木釘は喚鐘を「静かに支える」基点。羽は「派手に主張するため」ではない | 静けさ。装飾的な動き・グラデーション・粒子背景を置かない。強い色は緑一色だけ |
| 図は構造を作らず、すでにある構造に「輪郭を与える」「しるし」 | 主役は図そのもの。実画面と、公開パッケージが実際に生成した図だけを見せる。架空の画面は描かない |
| Readable を最優先。同じ地図を熟練度に応じて深く読める | 一つのセクションは「主張 → 証拠（画面・図・表）→ 次の一歩」。全体を見せてから細部を拡大する |

これはプロジェクトの造形判断であり、由来の文章を画面に載せることではない。由来そのものは About に置く。

## デザインと伝達の配分

- **伝達が先、デザインは図の語彙から。** 新しい装飾モチーフを発明しない。サイトの視覚的な個性は、
  製品の図がもともと持つ語彙（機器の枠、黒地のポートタグ、接続線、使用率の色）から取る。
  ポートタグ型のラベルは「機器:ポート」のように実際に図の要素を指す時だけ使う。
- **証拠は本物だけ。** Hero と事例は JANOG57 NOC の実画面。「構成をデータで扱う」の図は、
  `@shumoku/core` と `@shumoku/renderer-svg` がビルド時に YAML から生成した SVG で、手描きしない。
- **画像がない所は空けておく。** 欲しいが素材がない箇所は `ImageSlot` で枠と用途だけを示し、
  画面を捏造しない。公開前に差し替えるか、枠ごと外す。
- **動きは一つだけ、利用者の操作に応じて。** 接続先ポートの切替で図が差し替わる瞬間だけ。
  読み込み時のアニメーションや常時動く背景は置かない。
- **配色・文字・余白は既存の基盤を使う。** `color-system.md` の緑＋暖色ニュートラル、`ui.css` の
  間隔トークン、`site-container`、`LinkButton`。ホームの画像カードは `ui-kit.md` の 16/10/6px 入れ子。

## セクションの型

基本は `Section`（見出し・本文・証拠・行動）だが、全セクションを同じ枠に揃えない。
型を一つに統一した初版は、強弱のない「内容のない生成サイト」の見え方になったため撤回した。
内容の性質で形を変える。

- 「なぜ作るか」（`PHILOSOPHY.md` の「WiFi は天から降ってこない」）は文字だけの一段落。
  Home で唯一、大きな文字を使う箇所で、About の由来へつなぐ。
- 証拠が画面のものだけ画像を添える。連携は文章とロゴの行だけ、OSS は最新のブログ記事を並べる。
- 利用実績は JANOG57 の説明に加え、UEC・JANOG57・JANOG58 のロゴを戻す（初版で外していた）。

見出し上のラベル（eyebrow）、番号、同寸カードの格子、末尾矢印は使わない。区切りは余白と
`--ui-surface` の帯で付け、罫線は表・一覧・図の枠に限る。

足すかどうかの基準は「読む人の判断に必要か」だけ。見栄えのための要素（Hero への操作可能な図の
埋め込み、写真の並び）は足さない。
